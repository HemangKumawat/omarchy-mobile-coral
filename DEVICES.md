# Google Pixel 4 XL (`coral`) — Device Status Matrix

Up-to-date hardware status for the **Google Pixel 4 XL (`coral`, Qualcomm SM8150 / Snapdragon 855)** running mainline Linux `6.17.0-sm8150` + Arch Linux ARM / Omarchy Mobile (`Hyprland`).

Matches the subsystem categories published on [omamobile.org/devices](https://omamobile.org/devices/) and [`derekross/omarchy-mobile` PR #52](https://github.com/derekross/omarchy-mobile/pull/52).

**Legend (matching `omamobile.org/devices`):**
- **testing**: verified on real hardware, runs on our `coral` image built from the [SM8150 kernel tree (`v6.17.0-sm8150`)](https://gitlab.postmarketos.org/soc/qualcomm-sm8150/linux/-/tree/v6.17.0-sm8150) + this repository;
- **WIP**: bring-up in progress, some gates passed on hardware;
- **no**: not started, or blocked;
- **-**: the hardware doesn't exist on this device.
